Thiết Lập API Key

Bạn cần cung cấp API Key Gemini để sử dụng các tính năng của công cụ.

Hướng dẫn lấy API Key

  1. Truy cập Google AI Studio
  2. Đăng nhập
  3. Nhấn "Create API key"
  4. Dán vào ô trên

API Key được lưu cục bộ và không gửi đi đâu.
